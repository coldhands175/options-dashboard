# Check Git and Deployment Status

Get a comprehensive overview of the current state of the repository and deployments.

## Information to Show

1. **Current Branch**: Which branch are you on?
2. **Git Status**: Any uncommitted changes?
3. **Recent Commits**: Last few commits on current branch
4. **Branch Comparison**:
   - Is `dev` ahead of `main`?
   - Are there unpushed commits?
5. **Convex Deployment**: Which Convex deployment is currently running?

## Quick Command

Tell Claude: "Check git status" or "What's my current status?"
