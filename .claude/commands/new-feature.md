# Start New Feature

Create a new feature branch following the project's git workflow.

## Steps

1. **Ensure you're on dev branch and up to date**:
   - Switch to `dev` branch
   - Pull latest changes from remote

2. **Create feature branch**:
   - Create a new branch named `feature/[feature-name]`
   - Feature name should be descriptive and kebab-case

3. **Set up development environment**:
   - Ensure Convex dev server is running (`npm run dev`)
   - Ready to start coding

## Rules

- **Always branch from `dev`, never from `main`**
- **Use descriptive feature names**
- **Keep features small and focused**
- **One feature per branch**

## Quick Command

Tell Claude: "Start new feature [feature-name]" or "Create feature branch for [description]"
